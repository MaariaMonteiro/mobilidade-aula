# Projeto Pokémon Login — T.P Web e Mobile
Este projeto foi desenvolvido para a disciplina T.P Web e Mobile, com o objetivo de praticar conceitos iniciais de React, organização por componentes, navegação entre telas e controle de autenticação tanto na web quanto no Android.

A aplicação possui uma tela de login e uma tela principal com cards de Pokémons, utilizando componentes reutilizáveis para melhorar a organização do código.

# Objetivo
A ideia desse projeto foi aprender melhor como funciona o React na prática, principalmente a parte de componentes, navegação entre telas e controle de login.

O app funciona tanto na Web quanto no Android, seguindo a proposta do professor.
Também foi implementada uma verificação de autenticação para impedir que alguém acesse a tela principal apenas copiando e colando a URL no navegador.
