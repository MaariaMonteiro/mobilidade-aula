# Projeto Pokémon Login | Componente de T.P Web e Mobile

Este projeto foi desenvolvido para a disciplina T.P Web e Mobile, com o objetivo de praticar conceitos iniciais de React, organização por componentes, navegação entre telas e controle de autenticação tanto na Web quanto no Android.

A aplicação possui uma tela de login e uma tela principal com cards de Pokémons, utilizando componentes reutilizáveis para melhorar a organização do código.

---

# Objetivo

- Aprender melhor como funciona o React na prática
- Trabalhar com componentes reutilizáveis
- Implementar navegação entre telas
- Criar um sistema simples de autenticação
- Desenvolver uma aplicação compatível com Web e Android
- Impedir acesso direto à dashboard pela URL sem login
